ZENITH-INSPIRED DIGITAL BANKING WEBSITE — STUDENT PROJECT

FILES
-----
index.html  Main website structure and all page sections.
style.css   Complete styling, consistent red/white/charcoal palette,
            responsive layouts, hover effects and animations.
script.js   Page interactions and animation behaviour.

THE FOUR REQUESTED SECTIONS
---------------------------
1. What we do       #services
2. Digital banking  #digital
3. Our difference   #about
4. Security         #security

RUN LOCALLY
-----------
1. Extract this ZIP file.
2. Open the extracted folder in Visual Studio Code.
3. Open index.html with Live Server (recommended), or open index.html
   directly in a browser.
4. Use the navigation links to jump to each section.

CUSTOMISING
-----------
Edit the text and section content in index.html.
Edit colours, spacing, responsive layouts and animations in style.css.
Edit interactive behaviour in script.js.

NOTE
----
This is an educational, front-end student project inspired by Zenith Bank.
It is not an official Zenith Bank website and does not connect to real
bank accounts, process real payments or collect banking credentials.
